# ProofDeck — отчёт о готовности

Рабочий локальный MVP собран и проверен. Конкурсная подача ещё не завершена:
публичный Clips, GitHub и подтверждение получения заявки отсутствуют.

## Что получает пользователь

Редактор локализованных игровых карточек на настоящем Agent-Native 0.220.0:
свой CSV, физический макет, исходник и перевод, живой агент, предложения с
различиями, принятие/отклонение, глоссарий, история, согласование версии и PDF.
Данные сохраняются в PGlite через Drizzle. Агент и интерфейс вызывают общие
типизированные actions; AI не спрятан в обработчике обычного CRUD-действия.

Настоящий Codex использовал существующий локальный вход через ChatGPT. Ключ API
не копировался и не подставлялся из OAuth-файлов. Встроенные shell/browser/apps/
subagent-возможности отключены для редакторского запроса; запись в колоду
выполняет ограниченная поверхность действий приложения.

## Что реально запускалось

- `pnpm typecheck`: exit 0 на финальном коде.
- `pnpm agent-native:doctor`: exit 0, все 14 включённых guards, без находок.
- `verify_app.py`: 20 проверок реального action HTTP / Chromium / PDF.
- `verify_cancellation.py`: 3 проверки — overlap 409, отмена настоящего SSE и
  освобождение слота, отсутствие записи при ранней отмене.
- `verify_ui.py`: 5 проверок — 390 px без бокового скролла, клавиатура диалога,
  несохранённый preview, защита перехода/экспорта, reload и входной маршрут.
- `record_demo.py`: полный UI-путь с живой моделью, принятием, скачиванием PDF и
  историей. `page_errors=[]`, `http_failures=[]` в этом прогоне.
- Отдельно проверен реальный перезапуск сервера; это не повторное открытие
  объекта хранилища в том же процессе.
- `setup.sh`: завершён успешно в текущем checkout с уже имеющимся кешем.
- `prepare_video.py`: MP4/H.264, около 27,6 с, английские подписи; полная запись
  около 65,6 с также сохранена. Ожидание сокращено и раскрыто в подписи.

Это проверки разработчика. Независимая QA, реальные редакторы локализации,
равное сравнение с конкурентом/сильным GPT и чистая установка на другом
компьютере не выполнялись. Native-кнопка Stop отдельно не нажималась: проверена
отмена её HTTP/SSE-транспорта. Голосовой дорожки в видео нет.

## Пределы готовности

1. Механические проверки не доказывают равенство правил. Контрпример may → must
   проходит их; это проверено и явно оставлено задачей редактора. В демонстрации
   нажатия редактора автоматизированы; это не независимая лингвистическая оценка.
2. Один фиксированный шаблон, исходник English, проверенный пример German,
   латинский шрифт. CJK/Arabic, произвольный InDesign/PDF-импорт, многопользовательское
   совместное редактирование и печатный PDF-X/CMYK не входят в поставленный MVP.
3. Локальная модель использует личный CLI-вход. Production-режим этого bridge
   отключён; публичный хостинг требует отдельного изолированного agent host.
   Sites/Cloudflare Workers не запускает локальные Codex и Chromium.
4. Базовый шаблон иногда пишет предупреждение React о script в компоненте и
   сообщения о sourcemap; новых page errors в финальных UI-проверках нет.
5. Временной выигрыш и призовое преимущество не измерены. Исследованы реальные
   рабочие процессы и ближайшие альтернативы, но их продукты здесь не запускались.

## Конкурсная готовность

Для [Agent-Native Hackathon](https://www.builder.io/hackathon/rules) подготовлен
работающий продукт, раскрытие исходных компонентов и проектный текст заявки.
Публичная Clips-запись и полученная форма — обязательные оставшиеся шаги.
Локальный MP4 их не заменяет. Репозиторий пока локальный: `gh auth status`
не подтвердил вход в GitHub; URL репозитория от пользователя не получен.
Личные условия допуска участника требуют его подтверждения.

Следующий минимальный шаг: подключить выбранный GitHub и аккаунт Clips,
записать/опубликовать обязательную демонстрацию и отправить подготовленную форму,
сохранив подтверждение получения. Никакая такая публикация не заявлена как
выполненная. Для заявления о преимуществе нужен отдельный тест из EVALUATION.md.

`hackathon-prize-strategy` — правила, реальные процессы, конкуренты, честная

skill само по себе не считается доказательством работы.
